# 🐾 Pixel Pet - Your Tiny Digital Bestie

Meet Mochi, your adorable pixel-inspired virtual cat! 🍓

Pixel Pet is a cozy browser game where you feed your pet, play together, and help Mochi recharge while earning care points.

## ✨ Features

- 🍓 Feed Mochi and manage hunger
- 🎾 Play to increase happiness
- 🌙 Sleep to restore energy
- 📊 Live pet statistics and mood updates
- ⭐ Earn care points and level up
- 💾 Save your progress using browser local storage
- 🐱 Animated CSS pixel-inspired cat
- 📱 Responsive desktop and mobile layout
- ↻ Reset your game and start again

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Google Fonts

No framework, backend, or installation required.

## 🚀 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/jahnavist04/pixel-pet.git
   ```

2. Open the `pixel-pet` folder.
3. Open `index.html` in your browser.
4. Start taking care of Mochi!

## 🌐 Live Demo

Enable GitHub Pages in the repository's Settings → Pages.

Choose the `main` branch and `/ (root)` folder, then save.

Your game should become available at:

https://jahnavist04.github.io/pixel-pet/
